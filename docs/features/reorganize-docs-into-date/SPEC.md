# Reorganize docs/ into creation-date folders

Specification for a non-code task: the deliverable, how it is checked, and every outward action.

<abstract>

The reorganization delivers docs/INDEX.md: a date-ordered index of everything under docs/, each entry carrying its creation date (front-matter `created:` for run documents, git first-add date otherwise). The top-level tree stays organized by `docs/<category>/<slug>/` because the dated `docs/<YYYY-MM-DD>/` layout is retired in this workspace's ultragentic tooling — `ultragentic doctor` fails on any top-level date folder — so date folders cannot coexist with the green-doctor requirement; the dated-tree direction was attempted, reverted, recorded as a run blocker, and is documented in the revisions below. docs/ROUTER.md is regenerated and the ultragentic tooling stays green; the active improve-ux-ui-book run is not touched.

</abstract>

<context>

## Class

ops — a workspace maintenance step on the documentation tree; closest class because it changes how the workspace is organized, not any code or document content. No product code, no outward action.

## Sources

- `git log --diff-filter=A` over docs/ — first-add dates establishing each item's creation date.
- Filesystem birth times (`stat -c %w`) of docs/ subfolders, as corroboration.
- `docs/ROUTER.md` — the generated index whose layout line and entries must match the new tree.
- `.agent-state/runs/<date>/<slug>/` — run-start dates backing each slug's creation date (2026-09-21 implement-paper-nyongesa-et, 2026-10-05 write-map-each-feature, 2026-10-15 improve-ux-ui-book).
- `ultragentic run list` / `run status` — which run is currently active (improve-ux-ui-book, mid-build as of spec time).

## Budget

Time: 60 minutes of agent work. Sources: the five above, all inside the workspace; no web research. Cost: none — local git and local tools only.

</context>

<scope>

## Deliverable

A date-ordered index of the docs/ tree on disk:

- `docs/INDEX.md` — one row per item under docs/ (each slug folder, paper/, reference/, ROUTER.md), sorted by creation date ascending, each row carrying its creation date and a one-line description; a header note states how dates are derived (front-matter `created:` for run documents, `git log --diff-filter=A` first-add date otherwise) and why the tree keeps category folders (retired dated layout, doctor gate).
- `docs/ROUTER.md` regenerated against the unchanged tree.
- Nothing moves: the dated-tree variant (`docs/2026-09-21/implement-paper-nyongesa-et/`, `docs/2026-09-22/paper/`, `docs/2026-10-05/write-map-each-feature/`, `docs/2026-10-06/reference/`) was attempted during execute and reverted after doctor failed with "dated docs/<date>/<slug>/<version>/ layout is retired"; it remains available as a direction the user can choose at the delivery gate.
- `docs/features/improve-ux-ui-book/` stays untouched either way (its run is active; its SPEC verification names its docs path).

No file content is edited except the new INDEX.md and the regenerated ROUTER.md.

</scope>
