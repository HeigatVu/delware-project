# Docs index by creation date

One row per item under `docs/`, oldest first. Dates come from the document's
`created:` front matter for run documents, and from the git first-add date
(`git log --diff-filter=A`) for tracked files without front matter.

The tree itself stays organized by category (`docs/<category>/<slug>/`): the
dated `docs/<YYYY-MM-DD>/` layout is retired in this workspace's ultragentic
tooling and fails `ultragentic doctor`. This index is the date-ordered view over
that tree. The dated-tree alternative and this decision are recorded in
[docs/features/reorganize-docs-into-date/SPEC.md](features/reorganize-docs-into-date/SPEC.md).
