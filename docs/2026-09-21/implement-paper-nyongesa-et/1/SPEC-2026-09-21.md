# Specification: Python Implementation of Nyongesa et al. (2025) & Speech Repository on Delaware DementiaBank Dataset

## 1. Overview and Objective
This project implements the complete natural language processing (NLP), statistical, clustering, and machine learning pipeline described in:
- **Paper**: Nyongesa et al. (2025), *Artificial intelligence-driven natural language processing for identifying linguistic patterns in Alzheimer’s disease and mild cognitive impairment: A study of lexical, syntactic, and cohesive features of speech through picture description tasks*, Journal of Alzheimer's Disease, 106(1), 120–138.
- **Reference Code**: `https://github.com/cynthianyongesa/speech`
- **Target Dataset**: Delaware DementiaBank corpus (`/shared-data/dementiabank/Delaware`).

The objective is an end-to-end Python implementation that replaces the fragmented and mixed R/Python scripts with a clean, fully-tested, modular, reproducible Python package and CLI.

## 2. Architecture and Design

### 2.1 Package Architecture
The codebase is structured under `src/delware_speech/`:
- `chat_reader.py`: Robust parser for TalkBank/DementiaBank `.cha` files.
  - Parses headers (`@ID:`, `@Participants:`, `@Media:`).
  - Extracts participant speech (`*PAR:`) per task header (`@G: Cookie`, `@G: Cat`, `@G: Rockwell`, etc.).
  - Strips CHAT annotation codes (`[//]`, `[+ exc]`, `&*PAR:...`, timestamps `123_456`, phonological markers).
  - Excludes investigator utterances (`*INV:`).
- `demographics.py`: Metadata harmonizer.
  - Reads `demo-test-fixed.xlsx` (sheets `Control`, `MCI`, `Data Dictionary`).
  - Maps education level codes to approximate years of education per paper specification (0->0, 1->6, 2->9, 3->12, 4->13, 5->14, 6->14, 7->16, 8->18, 9->20, 10->21).
  - Standardizes diagnostic categories (`Control` -> Cognitively Unimpaired / Control, `MCI` -> Mild Cognitive Impairment).
  - Merges MoCA cognitive assessment scores.
- `features.py`: Full linguistic feature extractor for 53 features across 4 categories:
  - **Lexical Features**: POS frequencies & length-normalized rates (verbs, nouns, pronouns, adjectives, adverbs, interjections, determiners, conjunctions, prepositions, auxiliary verbs, particles, numerals), open-class words (OCW), closed-class words (CCW), content density (`ocw / ccw`), lexical diversity (unique lemmas / tokens), Type-Token Ratio (TTR), Brunét's index ($W = V / N^{0.165}$), Honoré's statistic ($R = 100 \cdot N \cdot (\ln N - \ln V_1)$), WordNet hypernym count, lexical sophistication (proportion of advanced words), lexical density, function word count.
  - **Syntactic & Structural Features**: Syntactic complexity formula $(2 \cdot \text{conj} + 2 \cdot \text{pron} + \text{noun} + \text{verb}) / \text{total\_counts}$, dependency parse syntactic complexity (clauses per sentence), passive voice constructions, noun-to-verb ratio (`RefRReal`), word count, sentence count, mean and std of sentence length, syllables, reading time, readability indices (Dale-Chall, Flesch Reading Ease, Coleman-Liau Index, Automated Readability Index).
  - **Semantic & Discourse Features**: Sentiment polarity and subjectivity (TextBlob), disfluencies count (pauses, fillers: uh, um, er, like, you know), discourse cohesion score (inter-sentence semantic relatedness), personal deixis rate, spatial deixis rate, temporal deixis rate.
  - **Temporal / Verb Tense Features**: Past tense rate, present tense rate, future tense rate.
- `pipeline.py`: Batch data processor.
  - Converts all `.cha` files in `/shared-data/dementiabank/Delaware/transcript/` to structured task data.
  - Merges transcript data with demographics.
  - Implements unique-participant filtering (one picture task per subject for aggregated analysis, prioritizing Cookie Theft and Cat Rescue as per paper).
  - Exports tidy Excel and CSV outputs (`processed_features_all.xlsx`, `processed_features_unique.xlsx`).
- `statistical_analysis.py`:
  - Group comparison tests: One-way ANOVA and Kruskal-Wallis non-parametric tests between diagnostic groups.
  - Post-hoc pairwise tests: Tukey's HSD and Mann-Whitney U with Bonferroni/FDR correction.
  - Effect size calculations: Partial eta-squared ($\eta^2$), Cohen's $d$, epsilon-squared ($\epsilon^2$).
  - Covariate adjustment (ANCOVA/regression controlling for age and education).
  - Correlation analysis: Pearson and Spearman correlations between linguistic features and MoCA scores.
- `clustering.py`:
  - Pearson correlation matrix calculation over numerical linguistic features.
  - Correlation-based distance matrix ($D = 1 - R$).
  - K-Means clustering (4 clusters) and Hierarchical Clustering (complete linkage) to match `Cluster_Analysis.R`.
  - Cluster validation: Silhouette score analysis and elbow method.
- `importance.py`:
  - Python replacement for `Importance_Features.R`.
  - Random Forest classification (10-fold cross-validation, hyperparameter tuning).
  - Mean Decrease in Gini impurity feature importance ranking.
  - Benchmark comparison with SVM (RBF kernel) and Gradient Boosting.
- `visualization.py`:
  - Python replacement for `t-SNE_PLOTS_.R` using scikit-learn TSNE.
  - Cluster correlation heatmaps with annotated cluster domains (Figure 3).
  - Feature distribution violin plots (Figure 5).
  - Radar plots across picture tasks (Figure 4b).
  - MoCA vs feature correlation scatter plots with linear regression fits (Figure 6).
- `cli.py` / `main.py`: Unified CLI to run any stage or the entire pipeline.

## 3. Acceptance Criteria
- **AC-1 (Data Ingestion)**: All `.cha` files from `/shared-data/dementiabank/Delaware/transcript/{Control,MCI}` are successfully parsed, participant speech is isolated, and demographics from `demo-test-fixed.xlsx` are correctly merged with education years mapped.
- **AC-2 (Feature Extraction)**: The 53 linguistic features are extracted without errors, null values, or crashes on Delaware transcripts.
- **AC-3 (Statistical Analysis)**: Diagnostic group comparisons (ANOVA / Kruskal-Wallis, post-hoc tests, effect sizes) and MoCA correlations are computed and exported to tables.
- **AC-4 (Clustering & Dimensionality Reduction)**: 4-cluster correlation clustering, dendrogram, silhouette scores, and 2D t-SNE projections are generated in Python.
- **AC-5 (Feature Importance & ML)**: Random Forest classifier with 10-fold CV is executed, and top 20 Gini-ranked predictive features are saved and plotted.
- **AC-6 (Visualizations)**: Publication-ready figures corresponding to Figures 3, 4, 5, 6, and t-SNE of the paper are rendered and saved as PNGs.
- **AC-7 (Test Suite & Quality)**: Test suite covering all modules runs with >=80% coverage and passing `pytest`, and codebase passes `flake8`.
