# Tasks: Python Implementation of Nyongesa et al. (2025)

## Task 1: Implement CHAT parser and Demographics harmonizer
- [ ] Create `src/delware_speech/chat_reader.py` with robust TalkBank parsing for `.cha` files.
- [ ] Create `src/delware_speech/demographics.py` with education mapping and MoCA score extraction.
- [ ] Create unit tests in `tests/test_chat_reader.py` and `tests/test_demographics.py`.

## Task 2: Implement 53 NLP linguistic feature extraction engine
- [ ] Create `src/delware_speech/features.py` implementing all 53 linguistic features:
  - Lexical (POS counts/rates, open/closed class words, content density, diversity, TTR, Brunét, Honoré, hypernyms, sophistication, density).
  - Syntactic & Structural (syntactic complexity, clauses per sentence, passive voice, readability metrics, syllables, reading time, sentence lengths).
  - Semantic & Discourse (polarity, subjectivity, disfluencies, cohesion score, personal/spatial/temporal deixis, verb tenses).
- [ ] Create unit tests in `tests/test_features.py` verifying all 53 features on test utterances.
